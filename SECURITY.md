# Security Policy

## Scope

This policy covers the code in this repository only. Vulnerabilities in
third-party dependencies, datasets or pretrained model weights should be
reported to their respective maintainers.

## Reporting a Vulnerability

Please do not open a public issue. Report vulnerabilities privately through
GitHub's [private vulnerability reporting](https://github.com/AndreKoraleski/find-those-polyps/security/advisories/new).
